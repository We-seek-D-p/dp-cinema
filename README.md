# DP-CINEMA

# Описание сервисов

## Django

Основной сервис для клиента. Регистрация, авторизация, взаимодействие с сущностями User, Movie и т.п. - всё здесь.

#### Детали

+ Загрузка фильма принимается админами в Django, но сервис ответственен только за сохранение метаданных о фильме в БД,
  не
  за сохранение фильма в S3 хранилище.
+ Не отвечает за рецензии на фильмы, но модерация происходит в админке Django

## FastAPI

Сервис для тяжелой фоновой задачи - сегментация видео и отправки сегментов в S3. Принимает фильм от Django со статусом
PROCESSING, а по завершении работы, в случае удачной обработки, посылает запрос на изменения статуса READY.

## Flask

Сервис, который имеет, в отличии от FastAPI, публичные ручки - отвечает за рецензии на фильмы. В сервис-слое оповещает
Django запросом на модерацию, оставляя статус PENDING у рецензии. После модерации в админке Django, посылается запрос во
Flask на изменение статуса, в зависимости от решения модерации.
